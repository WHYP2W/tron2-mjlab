# VeloWB 接口约定

状态：用于仿真研究的第 1 版接口，不是已经验证的实机驱动。
实现遵循提供的 v1.3 方案。软件测试通过，不代表已经验证动态平衡、跟踪性能、
动力学适应能力或仿真到实机的迁移效果。

以下原始约定对应 `control_profile=standard`；`control_profile=wbc` 的差异见末尾迁移章节。

## 机器人与坐标系

- 论文主平台：平面上的 TRON2A WFYG。保留 SFYG 作为参考平台。
- 资源包中的 YG XML 只有一条 PiperX 形式的机械臂运动链，从 `arm1_Joint` 到
  `arm6_Joint`，末端为 `gripper_pick`。不能根据上游硬件介绍推断该仿真模型具有双臂。
  夹爪关节保持固定。
- 原有行走任务仍固定整条机械臂，保留 10 维动作。
- VeloWB 启用机械臂。默认从模型中移除 `arm1_Joint`，使其固定在 XML 零位；
  `lock_arm_yaw=false` 可恢复该关节。两种机器人形态均对应 15/16 维动作。
- 锁定该关节不等于从数学上消除其他关节对世界系偏航运动的贡献。
  必须测量基座与机械臂实际承担的偏航运动，不能直接假定分工已经成立。
- 世界系采用 MuJoCo 世界坐标系，+Z 向上。单位为米、秒、弧度、N 和 Nm。
- 四元数顺序为 `wxyz`。六维空间速度（twist）顺序为 `[vx, vy, vz, wx, wy, wz]`，
  各分量均在世界坐标系表达。
- 基座参考点为 `base_Link` 原点，而不是基座的惯性质心。
- 末端执行器（EE）位姿使用位于现有 `gripper_pick` 坐标系的 site `robot/ee`。
- 策略周期：0.02 s（50 Hz）。物理仿真与 PD 积分周期：0.002 s（500 Hz）。

### 机械臂初态

机械臂关节初始角度统一为零：`arm1` 至 `arm6` 均为 0 rad，初始关节速度也为零。
锁定的 `arm1` 保持 XML 零位，腿部与轮子的原有初态不变。
零关节角表示模型定义的关节零位，不代表连杆在世界系中全部水平或共线；
XML 中各连杆的安装位置与固定旋转仍然生效。

此前实现曾自行使用 `[0, 1.2, -1.4, 0.2, 0, 0]` 的机械臂初态，现已按要求纠正。
已有训练进程仍使用启动时载入的旧初态，不会因修改代码而自动改变。
旧检查点的训练接口记录也不会被覆盖；从全零初态回放旧策略属于初态变化后的测试，
不应当作原训练配置下的性能结果。正式使用全零初态时应重新训练，不能直接沿用旧结果。

## 状态估计器

`ArmKinematics` 在初始化时从模型提取一次名义运动学树。在线正运动学（FK）只使用
关节位置、关节速度以及基座位姿和空间速度，不读取仿真末端位姿、仿真 Jacobian、
接触力或随机化后的质量。世界系速度包含：

```
v_EE = v_base + omega_base x (p_EE - p_base) + R_WB J_linear(q) qdot
omega_EE = omega_base + R_WB J_angular(q) qdot
```

六维速度估计、末端位姿、名义 Jacobian 和名义机械臂质心（COM）均采用批量 Torch 运算。
名义质心是几何特征，不是反作用力/力矩预测，也不是真实动力学预测。
测试覆盖两种机器人形态和两种偏航设置，分别在仅基座运动、仅机械臂运动及二者同时运动时，
与独立的 MuJoCo site 真值对照。

仿真传感器链路在 FK 之前加入编码器噪声、姿态/里程计噪声、可选的位置随机游走漂移、
传感器时延及额外的里程计时间戳错位。轨迹日志保留编码器与里程计时间戳。
噪声系数为 1 时，各项标准差为：关节位置编码器 0.002 rad、关节速度 0.02 rad/s、
基座位置 0.002 m、姿态扰动 0.005 rad、基座空间速度各分量 0.015。
这些数值是初始建模假设，不是实测的硬件噪声规格。

## 学生策略观测

基础观测按以下顺序排列：

1. 估计的世界系基座空间速度（6 维）。
2. 投影重力（3 维）。
3. 估计的世界系基座旋转矩阵前两列，按行展开（6 维）。
4. 相对于默认值的关节位置，按模型关节顺序排列；轮子转角项置零。
5. 按模型关节顺序排列的关节速度，乘以 0.1。
6. 上一步实际施加的归一化全身动作，按动作顺序排列。
7. 机械臂积分位置目标减去测得的机械臂关节位置。
8. 编码器采样距当前时刻的时间，然后是里程计采样距当前时刻的时间，单位为秒。
9. 下述任务特征。

速度任务特征包括：指令除以限幅值、估计末端空间速度除以限幅值，以及二者之差。
`error` 和 `cmd_meas` 消融配置会移除相应特征组。
速度策略网络及其历史编码器均不接收期望末端位姿、位姿误差、基座绝对位置、
接触参数或域随机化参数。

B0 改为接收相对基座原点的期望位置（在世界系表达的向量）、期望旋转矩阵前两列、
世界系位置/姿态误差，以及测得的末端空间速度除以限幅值。
它使用位姿跟踪奖励，其余底层控制接口与速度方法共享。

启用 IK 观测时，追加归一化的全身运动先验。启用前瞻观测时，追加
100/200/300/400 ms 的预测采样点。每个采样点包含关节位置 q；可选加入末端位置、
旋转矩阵前两列及空间速度；还可加入名义质心和展开后的 Jacobian。
前瞻从当前 IK 机械臂速度出发，固定名义基座坐标系和轮子运动贡献，
并在后续时刻重新计算机械臂 IK。它不预测基座运动、接触、加速度或反作用力。

历史窗口使用不含 IK/前瞻的基础观测，按从旧到新的顺序排列。
在 50 Hz 下，`history_seconds=0.4` 保存 20 个样本，包含当前样本。
设置为零秒时只保存一个当前样本，用作历史长度对照，并不意味着使用循环神经网络。
环境重置后，用新回合的第一帧观测填充历史窗口，不保留上一回合数据。

## 动作接口

动作顺序为腿、轮子（仅 WFYG）、启用的机械臂关节。
具体关节名、默认值和观测形状保存在每次运行的 `interface.json` 中。

- 腿：默认关节位置 + 0.25 * 归一化动作，通过位置 PD 执行。
- 轮子：10 * 归一化动作，单位为 rad/s，通过速度控制执行。
- 机械臂：将 1.5 * 归一化动作作为 rad/s 速度，以 50 Hz 积分得到位置目标；
  按模型关节限位裁剪后，通过位置 PD 执行。积分状态包含在观测中。
- 策略输出以及 IK 与残差合成后的指令均裁剪到 [-1, 1]。
- B7/residual：归一化的名义 IK + `residual_bound` * 裁剪后的策略残差。
- B6/observation：IK 仅作为输入信息，策略输出完整动作。
- B5：仅使用 IK，腿保持默认姿态。没有隐藏的学习式机械臂控制器或独立平衡控制器。
  跌倒必须作为实验结果记录，不能当作缺失样本删除。
- 动作变化率正则项使用经过 IK 合成和时延后实际施加的动作。

轮子/机械臂 IK 是阻尼最小二乘几何先验，轮子对应的 Jacobian 列采用平面无滑移假设。
轮半径和名义站姿轮距从机器人模型读取。它不是包含完整接触动力学的全身二次规划（QP）；
腿部平衡由强化学习（RL）学习。SFYG 使用仅机械臂的几何先验。
零指令对应的先验为零，因此没有在先验中手工写入机械臂动态补偿规则。

机械臂 PD 刚度/阻尼 60/3、力矩限幅 30 均为尚未标定的仿真值。
沿用的腿部和轮子增益也未经实机验证。
未完成标定且未接入平台安全控制器时，禁止将这些目标直接发送给真机。

## 外层控制器

外层 PD 使用 `Log(R_des R_actual^T)`，这是在世界坐标系表达的姿态误差。
默认 Kp=2、Kd=0.15、低通截止频率 3 Hz；各分量变化率限制分别为
0.5 m/s^2 和 1 rad/s^2，并叠加期望空间速度前馈。
指令限幅与训练范围一致，默认为 `[0.15, 0.1, 0.1, 0.25, 0.25, 0.3]`。
每个控制采样时刻调用一次 `set_pose`。`set_twist` 用于注入伺服测试指令。
同一控制时刻的重复写入不会额外推进传输时延队列。

指令时延作用于速度接口。B0 没有该接口，因此与 B0 比较时应使用共同的传感器/动作时延，
而不是速度指令传输时延消融。速度评估指标使用请求的指令，因此传输时延会计入相位滞后。
训练奖励跟踪实际收到的指令。位姿轨迹任务的速度指标使用各方法共同的期望轨迹前馈，
而不是每种方法自身外环产生的修正量。

## 教师策略与训练

特权输入包括：末端空间速度真值（GT）、基座空间速度真值、全身质心位置/速度、足端力、
负载质量/质心、摩擦系数、PD 强度倍率和动作时延。
附加负载采用 25 mm 的惯量等效球体表示，名义质量为 0.0001 kg；质量与惯量保持一致地随机化。
两个接触表面都设置相同的摩擦值，避免 MuJoCo 取较大摩擦系数时掩盖随机化效果。

B4/CTS 将固定大小的并行环境分成教师组和学生组，各占一半。
两组共享同一个策略网络并使用 PPO；教师编码器接收特权输入，学生编码器接收可部署观测历史。
PPO 复用 rsl_rl 的现有实现。PPO 更新后，在同一批采样数据上仅更新学生编码器，
使用潜变量均方误差（MSE）对齐，并对教师目标停止梯度。
这种分步优化的 CTS 风格实现，不宣称逐项复现参考论文的优化器。

B3 将相同总采样预算的前 70% 用于教师 PPO；随后冻结教师编码器、共享策略网络和价值网络，
利用学生采样轨迹训练学生潜变量与动作模仿。检查点保存训练阶段及阶段分界，供恢复训练使用。

评估和导出始终选择学生策略，可以在没有特权输入和角色标记的情况下运行。
`student_policy.pt` 是 TorchScript 模型，输入为 `(actor_observation, history)`；
无历史策略可传入空的历史张量。该文件只导出神经网络，不包含 FK、IK、外层 PD、
时间戳同步或执行器驱动；这些功能仍需通过各自明确的接口接入。

## 实现边界

- 当前仅支持平面实验，不宣称实现 MPC、感知、物体交互、复杂地形或坡地能力。
- 自碰撞过滤沿用行走配置。关节限位与非足部触地终止，不等于已经验证机械臂自碰撞规避。
- 尚未实现硬件通信、状态估计融合/标定、看门狗、急停或电机接口验证。G6 仍待完成。
- 公开再分发前，仍需确认上游网格资源的来源声明。

## WBC 参考设计迁移

这是把师兄的工程设计移植到现有 mjlab 训练链路，不是旧策略权重的直接部署，
也不是 PhysX 到 MuJoCo 的逐项数值复现。参考来源为
[师兄动作与奖励配置](../tron2WBC/source/ext_loco/ext_loco/tasks/locomanipulation/EE_pose/config/limx/Tron2wheelArm_EEtwist_env_cfg.py)、
[执行器配置](../tron2WBC/source/ext_loco/ext_loco/assets/limx.py) 和
[CTS 实现](../tron2WBC/rsl_rl/rsl_rl/algorithms/ppo_cts.py)。旧成品对应 `fd4deca`，
其五维解耦命令不等于目前源码的六维末端空间速度命令。

### 机械与动作接口

- 仅用于 WFYG。机械固定 `arm1`、`arm6` 和夹爪；启用 `arm2–5`。
- 默认腿和臂关节位置均为零，基座默认高度 0.85 m。训练重置会添加关节位置
  ±0.2 rad、关节速度 ±0.5 rad/s，以及参考配置中的基座速度扰动；随机位置裁剪到软限位。
  因此“默认零位”不等于每次随机重置后的实际关节值全零。
- 14 维动作顺序：左腿 4、右腿 4、机械臂 `arm2–5`、左右轮。
- 腿臂目标为默认位置 + scale * action，不再积分机械臂速度。腿 pitch/roll/knee
  scale=0.2192，腿 yaw=0.15，arm2/3=1.0，arm4/5=0.5；轮速 scale=7.0 rad/s。
- WBC 位置动作按真实关节限位裁剪，不沿用标准接口的 [-1,1] 裁剪；轮速目标限制为
  ±41.89 rad/s。零残差返回默认位置，不代表全身在世界系静止。
- 腿主关节 PD=139.41/17.75、力矩上限 130；腿 yaw=182.14/23.19、上限 60；
  轮阻尼 1.32、上限 22；arm2/3=50/2、arm4/5=30/3、上限均为 100。
  转子惯量与轮摩擦损耗采用参考配置。以上仍是仿真参数，不是实机安全认证。
- 物理 200 Hz，策略 50 Hz。`actuator_delay_steps=4` 表示每个环境在重置时采样
  0–4 个物理步的控制传输时延，即 0–20 ms；当前全身共用同一时延，参考代码各执行器组
  独立采样时延，这一点未逐项复现。
- 开启自碰撞；保留当前项目更严格的 55° 倾角和非足触地终止，另加入 0.25 m 基座高度终止。
  不复制参考代码 2% 概率接触终止。自碰撞已纳入仿真，但尚未完成所有构型的碰撞模型标定。

### 任务边界

- `wbc_plain` / `wbc_cts`：世界系六维空间速度，策略不含末端位姿误差。
- `wbc_height`：heading 系六维空间速度，Vz 另积分为世界高度目标；追加高度误差观测，
  用高度跟踪奖励替代 Vz 速度奖励。绝对高度范围 0.05–1.6 m，并限制目标在实际高度 ±0.15 m。
  重置后在新 FK 状态可用时重新锚定，不用旧回合位姿；同一控制步反复设置指令不会重复积分。
- heading 仅绕世界 Z 轴旋转基座偏航角，不是随基座 roll/pitch 一起旋转的 body 系。
  回放面板会显示 `World` 或 `Heading`，高度工程版还显示 `+ Z Hold`。
- 新 WBC 默认命令每 5 s 重采样；30% 为零段，其余为常值，范围为
  `[0.5, 0.2, 0.5, 0.5, 0.5, 0.5]`。它没有把旧五维中的腕关节速度、基座偏航率
  当作末端角速度；此迁移保留六维末端接口，旧 69D 模型不可直接使用。
- WBC 位置动作目前不与现有速度型 IK residual/preview 混用，配置会明确拒绝。
  如需接入，必须先定义位置先验的单位和动作顺序，不能直接相加。

### 奖励与动力学

迁移了分轴跟踪、存活、roll/pitch 角速度、基座加速度、臂限位门控的竖直加速度、
动作一阶/二阶变化、力矩变化、加权力矩/功率、轮子空闲转速、腿速度、关节加速度、
位置/速度/力矩限制、腿 yaw 约束、膝/髋俯仰对称、轮地滑移和接触奖励。
不加入旧版对整个基座静止或机械臂空闲速度的额外惩罚，以免压制零指令主动补偿。
这属于任务分工的软奖励，不是策略后面的独立机械臂跟踪器。

轮地滑移按轮体接触点切向速度计算，半径从当前模型读取，为 0.1 m，
不照抄参考奖励中的 0.128 m。基座加速度用相邻控制步速度差计算，
而不是 PhysX 的瞬时刚体加速度。接触力使用 MuJoCo 传感器，不与 PhysX 接触数值逐项等价。

预设增加基座质量偏移 [-1,3] kg、质心范围 [0.03,0.02,0.03] m、腿轮质量/惯量倍率
[0.8,1.2]、摩擦 [0.4,1.2]、PD 倍率 [0.8,1.2]。质量变化同步缩放惯量。
不引入臂负载；接触恢复系数、分别静/动摩擦以及腿轮以外的参数误差未逐项复制。
Student 仍走当前 FK 估计链路，不改回仿真末端真值直接加噪。

### 学习与兼容性

- 网络为 512/256/128，策略和价值输入使用经验归一化。WBC 基础观测追加关节力矩，
  纯速度 Actor 为 95D，含高度误差时为 96D；不是师兄旧版的 69D。
- CTS 使用 5 帧历史（0.1 s）、64D latent、512/256 编码器、75% 教师环境。
  历史逐帧复用 Actor 归一化，Teacher 的特权输入有独立归一化。
- PPO 阶段对 Student latent 停止梯度；Student 用 Teacher latent 监督更新。
  仍复用现有 rsl_rl PPO 和本项目分步更新，编码器结构不与师兄旧残差 MLP 逐层相同。
- 有限单步奖励裁剪到 ±5，非有限数值直接报错，不静默掩盖；不同奖励尺度不可直接比较总 reward。
- 导出的 TorchScript 已包含归一化，输入原始观测/历史，不能在外部重复归一化。
- 标准 15 维和 WBC 14 维检查点不能互相续训。原标准检查点仍可加载；标准零位重置另修复了
  软限位隐式偏移，旧运行的实际初态可能与修复后的严格零位不同，不宣称轨迹逐位可复现。
- 每次训练保存完整配置、实际动作向量顺序、比例、坐标系、高度反馈开关和延迟范围。
- 高度工程版不能作为纯速度 B1 通过 G2；WBC 的 CTS 正式训练需要同一 `control_profile`
  的纯速度 G2 通过记录，标准 B1 的 G2 报告不能直接替代。
